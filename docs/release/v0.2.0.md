# ai-security-scanner v0.2.0

Release channel: stable

## Highlights

- The report layer keeps every severity visible, including zeros, and distinguishes zero from an unmeasured value.
- A check without a verdict is no longer called untested, and a connection test is named as not a scan in both languages.
- Tables are captioned, each header says what it heads, evidence records carry what the scanner actually reported, and the Chinese report uses complete Chinese sentences rather than translated fragments.
- The product can propose upstream adapter refreshes; the client decides whether a refresh becomes a pull request back to main, and a refresh never claims more than was actually checked.
- Every engine build input is gated on a recorded hash.
- New coverage includes MCP Armor static configuration results, agentic radar workflow inventory, and garak probe results read without inventing a severity.

## Desktop packages

The [published v0.2.0 release](https://github.com/teddashh/ai-security-scanner/releases/tag/v0.2.0)
offers **Linux x86-64 Debian `.deb` only**. Windows MSI/NSIS and macOS DMG installers are
**not offered** in this release.

已發布的 v0.2.0 **僅提供 Linux x86-64 Debian `.deb`**；此版本**未提供 Windows MSI／NSIS 與 macOS DMG 安裝檔**。

The release workflow defines candidate build and qualification lanes for Linux, macOS, and
Windows; a lane can finalize as `not-offered`. The published `RELEASE_NOTES.md` and
`release-metadata.json` record the actual offering. Published files carry their own exact
checksums, runtime manifests, engine notices, SBOMs, and platform qualification records.
